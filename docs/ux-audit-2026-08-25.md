# Dadabase UX audit — 2026-08-25

## Scope & method

Full-app review of the running product, two days after the [2026-08-23 audit](./ux-audit-2026-08-23.md), covering everything shipped since (AI chat page, provider presets, DuckDB/CSV/MSSQL/ClickHouse connections, tool/schema selection).

Four parallel live reviewers inspected real dev servers seeded from the e2e fixture (`e2e-sqlite`): home + all dialect forms (:3101), connection workspace core flows (:3102), AI chat page (:3103), global shell/cross-cutting (:3104). Evidence: scripted Playwright DOM audits (accessible names, disabled states, font census, overflow checks at 1280/1024/768/820/780/620px), screenshots + vision OCR, console logs (`/tmp/ux-review-*.md` sources, `/tmp/ux-chat/`, `/tmp/ux-global/`). Read-only against user data throughout.

Findings severity: **P0** broken/trust-impacting · **P1** high friction · **P2** medium · **P3** polish.

## New findings

### Home & Connections

- **[P1] H1 — New-connection form permanently occupies ~half the home page** (1440px: saved connections left, full form right, no collapse/toggle). Two panes compete for primary action. Fix: collapsed-by-default CTA opening a dialog or dedicated route; optional compact "quick connect" strip.
- **[P1] H2 — `/connections/new` is a dead route**: with stale/absent params it renders "Connection unavailable" instead of the creation form. Nothing can deep-link "add connection". Fix: render form or redirect home.
- **[P1] H3 — Saved-connections table won't scale**: no favorites/pinning, no last-opened recency, no health/status column, no tags/dialect grouping; similarly named connections indistinguishable beyond raw endpoint string.
- **[P2] H4 — Dialect shown as lowercase enums** (`sqlite`, `csv`) in the table vs capitalized labels in forms; no dialect icons where users scan across 8+ dialects.
- **[P1] H5 — No file picker for SQLite/DuckDB/CSV paths** — free-text absolute paths only; CSV's directory mode indistinguishable until a test fails. Highest-friction input in the product. Fix: drag-and-drop zone minimum, validated path autocomplete ideally.
- **[P2] H6 — Validation is one generic banner far from fields** ("Check connection details…"), no inline field errors, no focus jump, duplicates on resubmit.
- **[P2] H7 — Provider preset select gives zero feedback**: empty placeholder (optionality invisible), and after picking Supabase nothing visibly changes — no port/SSL prefill shown, no helper text about what save will apply.
- **[P2] H8 — URL auto-prefixing silently mutates input** (`localhost:5432/db` → `postgres://…` via onChange); prefix map covers pg/mysql/mssql/clickhouse but apparently not libsql — bare libsql hosts risk getting a wrong prefix. Show the transformation explicitly.
- **[P3] H9 — Jammed label copy**: "…connection fieldsCredentials are never shown here." — hint and privacy note concatenated without separation (multiple dialect variants).
- **[P2] H10 — CSV size guards invisible until they fire**: ≥100 MB warn / >1 GB refuse, staged-edit rewrite semantics, and `.bak` backup behavior are documented nowhere near the path input.
- **[P3] H11 — "Security (SSL / SSH)" accordion promises SSH that doesn't exist** inside. Ship it or rename to "Security (SSL)".
- **[P2] H12 — Test vs Save affordance ambiguity**: two equal buttons, no inline test-result area, unclear whether Save validates first.
- **[P3] H13 — Read-only copy duplicated twice on one screen** with different wording.
- **[P3] H14 — Row actions hierarchy inconsistent**: Test/Open labeled; edit/delete/duplicate behind an icon kebab with empty accessible name.
- **[P2] H15 — Failed connection test shows just "Failed"** — no reason, timestamp, or retry hint. Surface the underlying error in an expander.
- **[P3] H16 — Empty search state renders an empty table shell**; needs "No connections match '…'" + clear action.
- **[P3] H17 — File paths verbatim in Endpoint cells** leak filesystem layout; show basename + ellipsized parent, full path on hover/copy.
- **[P3] H18 — Access column relies on text alone** ("Writes enabled"/"Read-only"); pair with an icon, verify contrast.

### Workspace (browse / grid / navigation)

- **[P0] W1 — View mode not deep-linkable** (violates the URL-state trust contract for `tab=structure|er`, `mode=sql`; back button loses your view).
- **[P0] W2 — Row-editor entry undiscoverable: double-click on a cell does nothing** (`role=dialog` count stays 0). If editing lives behind hover-only actions it fails discoverability *and* touch/narrow use. Core write flow effectively hidden.
- **[P1] W3 — Central empty state duplicates the sidebar navigator** (same search + same 6 tables twice on screen). Make the empty state a launcher (recent tables, saved queries, New SQL, Ask AI) with exactly one authoritative navigator.
- **[P1] W4 — ER legibility worst-case**: 41 sub-12px text nodes, no headings, no zoom/minimap/search affordances detected. Needs a font floor, fit-to-view default, minimap, searchable table index.
- **[P2] W5 — Pagination arrows silently disabled**; explain or hide ("Already on first page").
- **[P2] W6 — SQL editor defaults to light theme inside dark shell**; default to shell theme, keep manual override.
- **[P3] W7 — Sidebar collapse button is the last unnamed icon control** on grid/SQL surfaces.
- **[P3] W8 — Grid still carries 65 flat controls**; group by intent (view / query / edit / hazardous "Change" menu).

### SQL & Data

- **[P1] S1 — Saved queries / query history are buttons, not a library**: no search, names, folders/tags, result metadata, open-vs-rerun distinction.
- **[P2] S2 — SQL history stores raw queries with no retention/redaction/opt-out** (carried over, unresolved; queries contain sensitive predicates).
- **[P2] S3 — Snippet templates unverified quality**; in a table-independent workspace `SELECT * FROM` alone is useless — provide placeholders + schema-aware picker.
- **[P2] S4 — Unhandled `SqlError` from `query_logs` insert on SQLite fixtures** surfaces in console during normal sessions — erodes trust even outside chat.

### AI Chat (`/connections/$name/ai`) — grade today: C+

- **[P0] C1 — Consent gate unmounts the entire product**: pre-consent there is no composer/thread/hint — one checkbox floating in dead space (`ai-chat.page.tsx:660-676`). Users can't see what they're consenting to use. Always render the surface; disable only Send with an inline reason.
- **[P0] C2 — Keyless providers can't actually send**: settings accept Ollama/LM Studio ("No API key needed", key input hidden) but Send stays gated on `hasKeyForChat()` → eternal "Add an API key". Stale render/event issue makes 2 of 10 presets unusable.
- **[P0] C3 — Schema status lies**: "(0 tables in main)" while sidebar shows 6 and schema settings say "(6 total)". Three sources of truth disagree; the status line reads an unpopulated store pre-introspection. The token-saving indicator must be trustworthy.
- **[P1] C4 — `propose_sql` renders as "⚒ propose sql — Completed" with no visible SQL** in thread text. The core product moment is reviewing SQL before running: expand by default, or show purpose + one-line SQL preview with explicit expand.
- **[P1] C5 — Schema All/Selected/Auto switcher is three anonymous `<button>`s** — no radio role/`aria-checked`/group label; selected-state styling barely distinguishable (13/14 screenshots byte-identical).
- **[P1] C6 — Below 1024px the workspace sidebar vanishes with no replacement**, and at 620px the thread node itself leaves the DOM — page collapses into something unusable. Deliberate narrow strategy needed (overlay drawer or stacked layout).
- **[P1] C7 — First-run hierarchy**: post-consent viewport ~90% empty while Provider+Tools+Schema panels all sit expanded, competing with the empty thread. Collapse configured panels; one primary CTA ("Ask your first question").
- **[P2] C8 — Message DOM order puts text before role label** — verify reading order isn't content-before-authorship for AT.
- **[P2] C9 — Composer placeholder is Postgres-flavored on every dialect**; make dialect-aware.
- **[P2] C10 — Provider combobox unlabeled** (aria-label null); Base URL/Model use placeholder-as-label.
- **[P2] C11 — No streaming cue beyond generic "Generating…" pill** (no caret/typewriter, elapsed time, or step hints) and **no visible cancel/stop** mid-stream though transport supports it.
- **[P2] C12 — Threads list invisible to new users** — materializes only after first thread; add ghost entry/"conversations will appear here".
- **[P2] C13 — Legacy bare-string API-key localStorage doesn't enable Send** (JSON-object config does); two storage formats coexist silently — finish the migration.
- **[P2] C14 — Approval feedback loop ends at the button**: post-decision, the approved SQL's outcome (ran? rows? error?) isn't surfaced inline near the decision.
- **[P3] C15 — Thread-item header icon buttons lack tooltips/aria names.**
- **[P3] C16 — Settings saves give no confirmation feedback.**

### Global shell & accessibility

- **[P0] G1 — Command palette crashes on open** (⌘K): cmdk throws `Cannot read properties of undefined (reading 'trim')` — likely an undefined value/label in a registered command — and there is **no root error boundary** ("error wasn't caught by any route"). Palette unusable; AI discoverability currently rests on one rail button.
- **[P0] G2 — Theme flash + missing `color-scheme`**: theme applies post-hydration via effect (`src/hooks/use-theme.ts`) so every load paints light then flips dark; native scrollbars/selects render light inside dark UI. Fix: blocking pre-hydration script setting `html.dark` + `color-scheme: dark light`.
- **[P1] G3 — Static document title "Dadabase" everywhere**; routes indistinguishable in tabs/history. Per-route titles ("e2e-sqlite · Tables — Dadabase").
- **[P1] G4 — ConnectionSwitcher trigger has no accessible name** — the primary context switcher is anonymous to AT (regression vs 08-23 sweep).
- **[P1] G5 — Zero skeletons/spinners during initial loads**; routes pop in empty then fill (layout shift). Standardize skeletons + one spinner token.
- **[P1] G6 — One `aria-live` region app-wide**: chat streaming status, connection-test results, save confirmations are all invisible to AT.
- **[P2] G7 — No toast/dialog pattern for async failures** observed; errors are inline text only.
- **[P2] G8 — No `:focus-visible` rules shipped**; keyboard focus relies on UA defaults (tab order itself is logical).
- **[P2] G9 — Home tab order starts with the theme toggle**; utility toggles should end tab order, primary content first.
- **[P2] G10 — Mixed casing/tone**: "Test Connection"/"Save connection"/"Run selected SQL"; also "AI assistant" vs "Threads" terminology drift.
- **[P0→trivial] G11 — No favicon anywhere** (`link[rel*=icon]` absent).

### Responsive & theming

- **[P1] R1 — Chat page ≤1024px**: sidebar disappears without replacement; thread leaves DOM at 620px (see C6). Everything else verified overflow-free at 1280/1024/768 — remaining narrow work is density (workspace toolbar wraps into multiple rows at 768), not overflow.

## What to preserve (do not lose these in refactors)

- **Read-only-by-default safety contract**, consistently present across all 8 dialect forms, in plain language.
- **Masked credentials in endpoint display** (`postgres://dadabase:*****@…`).
- **Per-dialect form adaptation** — sqlite/libsql minimal; DuckDB explains `.duckdb`; CSV documents single-file-or-directory + DuckDB engine backing.
- **Complete preset roster** (Custom, CockroachDB, Neon, Supabase, TimescaleDB, YugabyteDB, MariaDB).
- **Structure view information design** (type/key/default presentation) — reference standard for other views.
- **SQL toolbar labeling discipline** — every icon control named; extend this pattern to ER and the remaining stragglers.
- **Rows / Structure / ER top-level mode split.**
- **Narrow-viewport zero-overflow baseline** on home/workspace/chat — keep as a regression benchmark.
- **Deterministic mock-SSE chat e2e harness** — excellent infrastructure; extend rather than replace.
- **Consent copy quality** (what leaves the machine, plainly stated).
- **Composer model picker + data-driven tools section** with plain-language descriptions and select all/none.
